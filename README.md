# نظام مكتب خدمات عامة - تطبيق جوال (PWA)

نظام حضور + فواتير PDF + نسب الموظفين، مصمم ليعمل كتطبيق على الجوال.

## المميزات
- واجهة مخصصة للجوال مع شريط تنقل سفلي
- قابل للتثبيت على الشاشة الرئيسية (زي التطبيق)
- تسجيل حضور وانصراف
- إصدار فاتورة PDF
- حساب نسبة 50% تلقائياً
- لوحة مدير كاملة

## التشغيل المحلي
```bash
pip install flask flask-login reportlab arabic-reshaper python-bidi pillow
python app.py
```
ثم افتح: http://127.0.0.1:5000

## التثبيت على الجوال (بعد الرفع على الإنترنت)
1. افتح الرابط من متصفح الجوال (Chrome أو Safari)
2. اضغط على قائمة المتصفح (⋮)
3. اختر **إضافة إلى الشاشة الرئيسية** أو **Install app**
4. سيظهر أيقونة التطبيق على جوالك

## الرفع على Render (مجاني) عشان يشتغل من أي جوال
1. اعمل حساب على https://render.com
2. New → Web Service
3. اربط مستودع GitHub أو ارفع الملفات
4. Build Command: `pip install flask flask-login reportlab arabic-reshaper python-bidi pillow`
5. Start Command: `python app.py`
6. بعد النشر خذ الرابط وافتحه من الجوال وثبّته
